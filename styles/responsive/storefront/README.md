# Storefront: responsive styles

Responsive styles for the storefront. The handover has no storefront page yet (nothing in `prototype/`), so this folder only holds this README.

- **Same type folders as the workspace** (`../workspace/`): `components/`, `layouts/` and `pages/`.
- **First line of every partial:** `@use "../../../variables" as *;`
- **Import them from the storefront's entry,** named from `styles/`: `@use "responsive/storefront/<type>/<name>";`.
